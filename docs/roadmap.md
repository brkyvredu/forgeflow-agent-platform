# Roadmap

## v0.1 — Foundation

- ADK coordinator and four specialists
- Stateless MCP repository tools
- Java analysis service
- PostgreSQL/pgvector memory
- OpenTelemetry traces
- Docker Compose and Kubernetes manifests
- CI, unit tests, adversarial fixtures, and documentation

## v0.2 — Authenticated developer workflow

- GitHub App authentication
- Pull request and issue tools with strict scopes
- MCP OAuth 2.1 resource-server support
- Tenant-aware database schema and row-level security
- Human approval service for write actions
- Provenance and confidence on memory records

## v0.3 — Deeper code intelligence

- Tree-sitter parsing for multiple languages
- Call graph and dependency graph extraction
- Incremental repository indexing
- Embedding and reranking benchmarks
- Contract-test generation from OpenAPI and AsyncAPI

## v0.4 — Production operations

- Managed GKE or Agent Runtime deployment
- Workload identity and secret manager
- Signed SBOMs and image provenance
- SLO dashboards, alerts, and cost controls
- Chaos tests and regional failover exercises
- Expanded public evaluation benchmark
